# Mehak Fatima — Personal Portfolio

A responsive personal portfolio website built with HTML5 and CSS3.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — styling, responsive layout, and mobile navigation

## Run locally
Open `index.html` in your browser. Internet is needed for the Google Fonts import.

## Customize
Update the profile, skills, and project cards in `index.html` as your experience grows. The current project cards are learning examples; replace them with completed projects as you build more.

## Built with
- HTML5
- CSS3 (Grid, Flexbox, media queries)
